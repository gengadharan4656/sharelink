Privacy Policy

ShareLink is built on a fundamental principle: your files and personal data should never leave your local physical network.

Effective Date: November 9, 2026 • Brand: Gen Soft Tech • App ID: com.gensofttech.sharelink

1. Architecture & Data Collection Overview

ShareLink is an offline-first, peer-to-peer file transfer utility. We do not collect, process, sell, monetize, or transmit your files, personal identification, or device metadata to any remote cloud servers.

  • No User Accounts: You do not need an email, phone number, password, or third-party login to use ShareLink.
  • No Cloud File Intermediaries: Files transferred using ShareLink travel directly between the sending device and receiving device across your local Wi-Fi or mobile hotspot. No intermediate copies are uploaded to the internet.
  • Zero Tracking & Analytics: The ShareLink application contains zero commercial tracking SDKs, zero advertising networks, and zero behavioral analytics trackers.

2. Cryptographic Zero-Knowledge Pairing

To protect your privacy even on shared or open Wi-Fi networks, ShareLink implements zero-knowledge pairing:

  • When an Android sender initializes a transfer session, a 256-bit pairing secret is generated locally using a cryptographically secure pseudo-random number generator.
  • This secret is encoded exclusively into the QR code's URL hash fragment (e.g. #pairingSecret). Per standard HTTP specifications (RFC 3986), the hash fragment is strictly evaluated in memory by the client's browser and is never transmitted over the local network wire.
  • Symmetric AES-256-GCM encryption keys are derived on-device using HKDF-SHA256. Neither external parties nor network eavesdroppers can view or decrypt your file stream.

3. Android Runtime Permissions & Scopes

ShareLink requests only the minimum OS permissions necessary to facilitate offline local transfers:

  • Camera (android.permission.CAMERA): Used strictly to scan QR codes for device pairing. No images, video recordings, or facial data are ever saved, stored, or transmitted.
  • Nearby Devices (android.permission.NEARBY_WIFI_DEVICES): Required on Android 13+ to discover nearby peers via mDNS, Wi-Fi Direct, and BLE without requesting coarse location.
  • Storage & Media: Used solely to allow you to select files you wish to transfer and to write incoming files to your device's standard public Downloads/ShareLink folder. ShareLink does not access files outside your explicit selection.
  • Notifications (android.permission.POST_NOTIFICATIONS): Used exclusively to display transfer progress in the foreground notification bar while large files are moving.

4. Separation of Public Website & Transfer Service

The website hosted at https://gengadharan4656.github.io/sharelink/ is a static informational distribution site hosted on GitHub Pages.

This public website is completely separate from the Android local transfer server. The public website does not act as a relay, does not receive file uploads, and does not retain file logs. Actual transfers are processed exclusively by the ephemeral HTTP server started on the Android sender device on your local private subnet.

5. Storage & Data Retention

ShareLink does not maintain permanent transfer manifests on disk. Once a transfer is dismissed, active session keys and memory references are zeroized in RAM (sessionKey.fillRange(0, length, 0)) to prevent cold-boot memory attacks.
